# Обновление валидации анкеты

- Кандидат видит конкретную причину ошибки возле каждого обязательного поля.
- Ошибочное поле подсвечивается красной рамкой.
- Страница автоматически прокручивается к первой ошибке.
- Сервер возвращает ошибки с привязкой к конкретным полям.
- Поля «Чем занимались ранее?», «Место обучения» и «Опыт работы и сферы» остаются необязательными.
- Убрано старое общее сообщение, в котором ошибочно упоминалось описание опыта.
